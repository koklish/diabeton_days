# Реестр

Одна запись — одни сутки. Файл `ГГГГ-ММ-ДД.json`, внутри все приёмы пищи за день,
замеры глюкозы, препараты и заметки. Файлы пишет приложение, руками их править не нужно
(следующая синхронизация того же дня перезапишет файл целиком).

`index.json` — сводка по всем дням: калории, углеводы, ХЕ, разброс глюкозы. Через неё
удобно быстро окинуть взглядом динамику, не открывая каждый день.

## Формат дня

```jsonc
{
  "schemaVersion": 2,
  "date": "2026-09-19",
  "updatedAt": "2026-09-19T18:42:11.000Z",

  // По какому правилу считались хлебные единицы в этот день.
  // basis: "total_carbs" — по общим углеводам, "net_carbs" — за вычетом клетчатки.
  "xe": { "gramsPerUnit": 12, "basis": "total_carbs" },

  "targets": { "kcal": 1800, "carbs": 180, "glucoseLow": 4, "glucoseHigh": 8.5 },

  // Итог за сутки. Всё уже посчитано: пересчитывать из items не нужно.
  "totals": {
    "kcal": 1742, "protein": 88.4, "fat": 61.2,
    "carbs": 186.3, "fiber": 24.1, "netCarbs": 162.2,
    "xe": 15.53,        // углеводы / gramsPerUnit
    "gl": 92.4,         // гликемическая нагрузка: сумма ГИ x усвояемые углеводы / 100
    "grams": 1630
  },

  "meals": [
    {
      "time": "08:30",
      "kind": "breakfast",          // breakfast | lunch | dinner | snack
      "kindRu": "Завтрак",
      "title": "Гречка с курицей",
      "source": "ai",               // ai — разобрано по фото, manual — введено руками
      "model": "claude-opus-5",
      "editedByUser": true,         // цифры правились человеком после разбора
      "photo": "photos/2026-09-19/ab12cd34.jpg",  // null, если фото не выгружалось
      "note": null,
      "totals": { /* как totals дня, но по этому приёму */ },
      "items": [
        {
          "name": "Гречка отварная",
          "grams": 180,
          "gramsRange": [150, 210],   // честный разброс оценки веса по фото
          "per100": { "kcal": 110, "protein": 4, "fat": 1.1, "carbs": 21, "fiber": 2.7 },
          "gi": 50,                   // гликемический индекс, null если неизвестен
          "confidence": "medium",     // high | medium | low
          "assumption": "Горка на десертной тарелке 20 см, высота ~2 см",
          "totals": { /* абсолютные значения порции */ }
        }
      ]
    }
  ],

  "glucose": [
    {
      "time": "07:10",
      "mmol": 6.4,
      "tag": "fasting",   // fasting | before_meal | post1h | post2h | bedtime | random | hypo
      "tagRu": "Натощак",
      "inRange": true,    // попадание в целевой коридор из targets
      "note": null
    }
  ],

  "meds": [{ "time": "08:00", "name": "Диабетон MR", "dose": "60 мг", "taken": true }],

  "weightKg": 92.4,
  "steps": 5400,
  "notes": "Свободный текст за день"
}
```

## Что важно помнить при чтении

- **`per100` — на 100 г готового блюда**, не сухого продукта. Абсолютные значения порции
  лежат рядом в `items[].totals`.
- **`confidence: "low"` и широкий `gramsRange`** значат, что вес оценён грубо. Такие позиции
  нельзя брать за основу выводов без оговорки.
- **`editedByUser: true`** — человек поправил цифры руками, им можно доверять больше,
  чем исходной оценке модели.
- **`carbs` включает клетчатку.** Усвояемые углеводы — это `netCarbs`.
- Записи за один день перезаписываются целиком при каждой синхронизации, поэтому
  история правок живёт только в истории коммитов.
