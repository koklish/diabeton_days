# Заметки для Claude

Проект ведётся на русском: интерфейс, комментарии, сообщения коммитов, промпты.
Владелец работает **только с телефона**, поэтому всё, что требует сборки, собирается
в GitHub Actions.

## Кто владелец и почему это важно

СД 2 типа, вес около 137 кг. **Главное — руки:** диабетическая полинейропатия,
туннельные синдромы, грыжа шейного отдела, по ЭНМГ отрицательная динамика за год.
Каждый лишний скачок сахара работает против нервов. Приложение не про похудение
и не про графики — про то, чтобы сохранить функцию рук.

12 лет чистоты после 8–10 лет зависимости. Еда сейчас работает как вещество: стресс,
скука, отпуск ведут к обжорству, и это ощущается как ломка. Диагноз психиатра:
генерализованное тревожное расстройство с депрессивной частью.

**Отсюда главное правило тона: никакой вины.** Вина его ломает, а не выпрямляет.
Это не мягкость, а рабочее требование:

- Никаких «вы нарушили», «норма превышена», красных экранов, восклицательных знаков.
- Никаких серий, которые обрываются и обнуляются.
- Никаких запретов «нельзя» — только «вот как это сработает у тебя» и цифра.
- Никакой бухгалтерии калорий до грамма: точность иллюзорная, давление реальное.
- **Победы называть вслух наравне с ошибками.** Собрал три тарелки без крахмала
  в буфете — это победа, а не «ну ладно». Его держит видимый прогресс.
- Честность в обе стороны: если делает ерунду — сказать прямо, до еды, а не после замера.

Печатать ему тяжело — руки затекают за минуту. Поэтому фото и голос основные,
длинные формы недопустимы, а шкалы сделаны крупными кнопками вместо ползунков.

## Медицинская рамка

Терапия: метформин утром и вечером, гликлазид (Диабетон MR), дапаглифлозин (Форсига),
семаглутид (Семавик) раз в неделю, плюс препараты по психиатрии.

- **Гликлазид роняет сахар.** По датчику за две недели минимум 2,5 и 1 % времени
  в зоне «очень низкий». Гипогликемия — не отметка в журнале, а протокол действий
  и счётчик эпизодов: это его главный вопрос к эндокринологу.
- **Алкоголь на гликлазиде опасен:** роняет сахар с задержкой 4–12 часов, чаще ночью.
  Низкая цифра сразу после выпитого не значит «пронесло».
- **Феномен зари.** Крахмал на завтрак бьёт сильнее, чем тот же крахмал в обед.
  Одна и та же тарелка оценивается по-разному в зависимости от времени суток.
- **Время вечернего метформина — его собственная гипотеза** (поздний приём даёт утро
  5,8–6,1). Оно фиксируется отдельно, статистика собирается автоматически.
- Не назначать, не отменять, не менять дозы. Максимум — «это вопрос к врачу».

Его правила, выстраданные на глюкометре, лежат в `app/src/profile.ts` и редактируются
в настройках. Разбор приёма опирается на них, а не на общие рекомендации.

## Как читать дневник

Реестр — в `days/`, по файлу на сутки. Формат описан в `days/README.md`; прочитай его
прежде, чем делать выводы. Главное поле — `meals[].response`: отклик сахара на приём
уже разобран, искать связь по временам не надо.

Когда он просит посмотреть динамику или найти закономерности:

- Смотри `meals[].plate` (структура тарелки), а не калории.
- Сравнивай утро с утром: заря делает завтраки несопоставимыми с обедами.
- Позиции с `confidence: "low"` — грубая оценка, и это надо оговаривать.
- Срыв объясняй обстоятельствами, а не характером. Когда он срывался месяц, причиной
  была отмена антидепрессанта, а не слабость.

## Устройство приложения

`app/` — React + TypeScript + Vite, упакован Capacitor в APK.

| Файл | Отвечает за |
|---|---|
| `src/profile.ts` | личный профиль: исключения, правила, цели, схема препаратов; сборка контекста для промпта |
| `src/lib/ai.ts` | разбор приёма: Claude со строгой JSON-схемой, вердикт «честно / не честно» |
| `src/lib/history.ts` | связь «приём → отклик сахара», компактная история для промпта |
| `src/lib/patterns.ts` | закономерности, считаются на устройстве без обращения к модели |
| `src/lib/safety.ts` | протокол гипогликемии, алкоголь, слабость рук, состояние |
| `src/lib/nutrition.ts` | единственное место расчётов КБЖУ и структуры тарелки |
| `src/lib/voice.ts` | голосовой ввод: системное распознавание Android, Web Speech в браузере |
| `src/lib/github.ts` | выгрузка в реестр, проверка приватности репозитория |
| `src/lib/export.ts` | формат файла, который уезжает в `days/` |

Правила, которые легко нарушить не подумав:

- **Расчёты живут только в `nutrition.ts`.** Иначе приложение и реестр разойдутся.
- **Модель отдаёт значения на 100 г, а вес отдельно.** Абсолютные цифры считает
  приложение: просить модель умножать ненадёжно.
- **Локальное сохранение важнее синхронизации.** Упавшая выгрузка не должна выглядеть
  как потеря данных.
- **Помощь при тяге и протокол гипо работают без сети и без модели.** В этот момент
  ждать ответа API нельзя.
- При изменении формата `days/*.json` поднимай `SCHEMA_VERSION` в `src/types.ts`
  и обновляй `days/README.md`.

## Проверка изменений

```bash
cd app && npm ci && npm run build      # типы + сборка
```

Android SDK в облачной среде недоступен (`dl.google.com` закрыт политикой), поэтому
APK проверяется только в GitHub Actions — workflow «Сборка APK».

Интерфейс прогоняется в Chromium через Playwright на вьюпорте 390x844: так видно то же,
что увидит владелец на телефоне.

## Приватность

`days/` содержит медицинские данные: сахар, вес, состояние психики, зависимость
в анамнезе, материалы для МСЭ. **Этот репозиторий публичный.** Дневник должен
синхронизироваться в отдельный приватный репозиторий; приложение само предупреждает,
если указанный репозиторий публичный, и выгрузка по умолчанию выключена.
