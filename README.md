# Дневник СД

Мобильное приложение для Android: фотографируешь тарелку — ИИ разбирает, что на ней,
оценивает вес порций и считает КБЖУ, углеводы, ХЕ и гликемическую нагрузку. Всё пишется
в реестр: одна запись на сутки, внутри все приёмы пищи, замеры глюкозы и препараты.
Реестр лежит в этом репозитории обычными JSON-файлами, поэтому его может читать и человек,
и Claude.

Сделано под конкретный случай: **СД 2 типа, терапия гликлазидом (Диабетон MR) и
дапаглифлозином (Форсига)**. Гликлазид способен вызывать гипогликемию, поэтому приложение
делает упор на равномерность углеводов по приёмам, а не только на суммарные калории.

> Приложение помогает вести учёт. Оно не ставит диагнозов и не назначает лечение.
> Решения о препаратах и дозах — только с лечащим врачом.

## Как поставить на телефон

1. Открой на телефоне [страницу релизов](../../releases/latest).
2. Скачай `diabeton-days.apk`.
3. Android спросит разрешение на установку из этого источника — разреши.
4. Новые сборки ставятся поверх старой: данные дневника сохраняются.

APK собирается автоматически при каждом изменении кода — компьютер для этого не нужен.

Есть и веб-версия (вкладка Actions → «Веб-версия»): открывается по ссылке в браузере
телефона и ставится на домашний экран через «Добавить на главный экран».

## Что настроить при первом запуске

Вкладка **Настройки**:

1. **Ключ Anthropic API** — создаётся на [console.anthropic.com](https://console.anthropic.com)
   в разделе API Keys. Без него фото разбирать нечем. Ключ хранится только на телефоне
   и уходит напрямую в `api.anthropic.com`.
2. **Реестр в GitHub** — владелец, репозиторий, ветка и fine-grained токен с правом
   `Contents: Read and write`. После этого каждая запись сама уезжает в `days/`.
3. **Расчёты** — сколько граммов углеводов считать за 1 ХЕ (в России 10–12), цели по
   калориям и углеводам, целевой коридор глюкозы.
4. **Схема препаратов** — постоянный приём, чтобы отмечать его в день одним нажатием.

## Как пользоваться

- **Фото еды** внизу экрана дня → снять или выбрать из галереи → модель разбирает снимок
  и показывает список блюд с весами и КБЖУ.
- Любую цифру можно поправить руками: вес, калорийность на 100 г, ГИ. Правленые записи
  помечаются, и при анализе им больше доверия.
- Если оценка мимо — впиши уточнение («хлеб два куска по 30 г», «жарил на ложке масла»)
  и нажми «Пересчитать». Модель сама подскажет, чего ей не хватает для точности.
- **Глюкоза** — замеры с привязкой ко времени и к ситуации (натощак, через 2 часа и т.д.).
  При значении ниже 3.9 приложение покажет порядок действий при гипогликемии.
- **История** — среднее за неделю и доля замеров в целевом коридоре.

## Приватность — важно

Дневник питания и сахара — это медицинские данные. **Репозиторий сейчас публичный**,
то есть всё в `days/` будет видно любому.

Варианты:

- **Рекомендуемый.** Оставить код здесь, а дневник синхронизировать в отдельный
  **приватный** репозиторий: создай его и укажи в настройках приложения. Код остаётся
  открытым, данные — нет.
- Либо сделать этот репозиторий приватным: Settings → General → Danger Zone →
  Change visibility. Тогда перестанет работать бесплатный GitHub Pages (веб-версия),
  но APK и релизы продолжат работать.

Ключ Anthropic и токен GitHub в репозиторий не попадают никогда — они живут
в хранилище приложения на телефоне.

## Что внутри

```
app/            приложение: React + TypeScript + Vite, обёрнуто Capacitor в APK
  src/lib/ai.ts       разбор фото: Claude с ответом по строгой JSON-схеме
  src/lib/github.ts   выгрузка записей в реестр через GitHub Contents API
  src/lib/db.ts       локальное хранилище (IndexedDB): дни и фотографии
  src/lib/nutrition.ts  расчёт КБЖУ, ХЕ и гликемической нагрузки
  android/            Android-проект Capacitor, ключ подписи в android/keystore
days/           реестр: по файлу на сутки + index.json. Формат описан в days/README.md
.github/workflows/    сборка APK и публикация веб-версии
```

Приложение работает без сети: записи сохраняются на телефоне и выгружаются в репозиторий
при первой возможности. Без интернета недоступен только разбор фото.

## Собрать локально

```bash
cd app
npm install
npm run dev              # веб-версия на localhost
npm run build            # сборка
npx cap sync android     # перенести сборку в Android-проект
cd android && ./gradlew assembleRelease
```

Нужны Node 22, JDK 21 и Android SDK (compileSdk 35).
