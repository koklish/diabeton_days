# Дневник СД

Приложение для Android под один конкретный случай: СД 2 типа, терапия гликлазидом,
тяжёлая полинейропатия рук и пищевая зависимость в анамнезе.

Фотографируешь тарелку — приходит короткий разбор **до того, как начал есть**: сколько
крахмалов, есть ли белок, какая доля овощей, как пойдёт сахар и вердикт «честно /
не честно». Всё пишется в реестр: одна запись на сутки, внутри еда, сахар, движение,
препараты, руки, состояние, ЖКТ. Реестр — обычные JSON-файлы, их читает и человек,
и Claude.

Чего здесь сознательно нет: подсчёта калорий до грамма, серий, которые обнуляются,
красных экранов и слова «нельзя». Вина не мотивирует — она топит.

Что есть вместо этого: **кнопка «Тянет»** с таймером волны и списком безопасного
сладкого, **протокол при гипогликемии** вместо отметки в журнале, **поиск связей**
в собственных данных и **раздел про руки** как доказательная база для невролога и МСЭ.

> Приложение собирает данные и помогает задать правильный вопрос врачу.
> Оно не ставит диагнозов, не назначает и не меняет дозы.

## Как поставить на телефон

1. Открой на телефоне [страницу релизов](../../releases/latest).
2. Скачай `diabeton-days.apk`.
3. Android спросит разрешение на установку из этого источника — разреши.
4. Новые сборки ставятся поверх старой: данные дневника сохраняются.

APK собирается автоматически при каждом изменении кода — компьютер для этого не нужен.

Есть и веб-версия (вкладка Actions → «Веб-версия»): открывается по ссылке в браузере
телефона и ставится на домашний экран через «Добавить на главный экран».

## Что настроить при первом запуске

Вкладка **Настройки**:

1. **Ключ Anthropic API** — создаётся на [console.anthropic.com](https://console.anthropic.com)
   в разделе API Keys. Без него разбирать фото нечем. Ключ хранится только на телефоне
   и уходит напрямую в `api.anthropic.com`.
2. **Целевые цифры** — дневной коридор, утро натощак, пик после еды, порог гипо.
   Заполнены личными значениями, поправь при необходимости.
3. **Еда** — исключения, белок, овощи, гарниры, безопасное сладкое. Исключения
   не попадут в разборы и предложения.
4. **Мои правила** — на них опирается вердикт по каждому приёму.
5. **Схема препаратов** — дозы не заполнены, впиши свои.
6. **Реестр в GitHub** — только приватный репозиторий (см. «Приватность»).
   Выгрузка по умолчанию выключена.

## Как пользоваться

- **Добавить приём** → снять или выбрать фото, либо продиктовать словами. Разбор
  приходит до еды: вердикт, структура тарелки, как пойдёт сахар и одно действие,
  которое ещё можно сделать.
- Любую цифру можно поправить. Правленые записи помечаются, и им больше доверия.
- Оценка мимо — впиши или продиктуй уточнение («хлеб два куска по 30 г») и пересчитай.
- **Сахар** — замер с привязкой к приёму: без этой связи не видно, как еда отозвалась.
  Ниже порога гипо приложение сразу показывает, что делать, ещё до сохранения.
- **Движение** — прогулка с привязкой к приёму. Без неё цифры сахара врут.
- **Руки** — крупные шкалы, метки провоцирующих нагрузок, время затекания
  и восстановления.
- **Тянет** — кнопка доступна с любого экрана. Таймер волны, безопасное сладкое,
  твои же принципы. Любой исход записывается одинаково спокойно.
- **Связи** — закономерности в собственных данных: срезает ли прогулка пик, как
  влияет время вечернего метформина, сколько было эпизодов гипо.

## Приватность — важно

В дневнике сахар, вес, состояние психики и материалы для МСЭ. **Этот репозиторий
публичный**, поэтому синхронизировать дневник сюда нельзя.

Заведи отдельный **приватный** репозиторий под дневник и укажи его в настройках.
Код остаётся открытым, данные — нет. Приложение проверяет это само: если указанный
репозиторий публичный, кнопка «Проверить» скажет об этом прямо. Выгрузка по умолчанию
выключена.

Ключ Anthropic и токен GitHub в репозиторий не попадают никогда — они живут
в хранилище приложения на телефоне.

## Что внутри

```
app/            приложение: React + TypeScript + Vite, обёрнуто Capacitor в APK
  src/profile.ts        личный профиль: исключения, правила, цели, препараты
  src/lib/ai.ts         разбор приёма: Claude со строгой JSON-схемой
  src/lib/history.ts    связь «приём → отклик сахара»
  src/lib/patterns.ts   поиск закономерностей, считается на устройстве
  src/lib/safety.ts     протокол гипо, алкоголь, слабость рук, состояние
  src/lib/nutrition.ts  расчёты и структура тарелки
  src/lib/voice.ts      голосовой ввод
  android/              Android-проект Capacitor, ключ подписи в android/keystore
days/           реестр: по файлу на сутки + index.json. Формат — в days/README.md
.github/workflows/    сборка APK и публикация веб-версии
```

Без сети работает всё, кроме разбора фото: записи, протокол гипогликемии, помощь
при тяге и поиск связей считаются на телефоне.

## Чего пока нет

Кухня с рационом, рецептами и блоком соусов; отчёты под каждого из пяти врачей;
разбор закономерностей моделью поверх арифметики.

## Собрать локально

```bash
cd app
npm install
npm run dev              # веб-версия на localhost
npm run build            # сборка
npx cap sync android     # перенести сборку в Android-проект
cd android && ./gradlew assembleRelease
```

Нужны Node 22, JDK 21 и Android SDK (compileSdk 35).
